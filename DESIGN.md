# DESIGN.md — Portfolio

> Концепция дизайна и структуры личного сайта-портфолио.
>
> Статус: согласована основа первой версии. Документ можно дополнять по мере развития проекта.

## 1. Идея проекта

Личный сайт для публикации проектов, экспериментов и идей.

На старте проектов ещё нет. Сайт должен выглядеть завершённым и аккуратным даже с пустым списком работ.

**Главный принцип:** сначала содержание, затем оформление. Не добавлять элементы только ради красоты.

## 2. Визуальное направление

**Minimal Synthwave**

Минималистичный интерфейс с лёгкой Synthwave-атмосферой.

- Почти чёрный фон с фиолетовым оттенком.
- Розовые и фиолетовые акценты.
- Мягкие градиенты без интенсивного свечения.
- Читаемая современная типографика.
- Много свободного пространства.
- Тонкие разделители и небольшие скругления.

### Цветовая палитра

| Назначение | Цвет |
|---|---|
| Основной фон | `#0D0B1B` |
| Поверхности | `#171225` |
| Фиолетовый акцент | `#9864CF` |
| Розовый акцент | `#D852A7` |
| Основной текст | `#F3E9FF` |
| Второстепенный текст | `#BEB0CF` |
| Разделители | `#332641` |

Цвета — отправная точка. Допускается небольшая корректировка контраста при реализации.

## 3. Структура сайта

### Главная — `/`

Содержит:

1. Header
2. Компактный Hero
3. Вертикальную ленту проектов
4. Минимальный Footer

### Проекты — `/projects`

Полный список опубликованных проектов.

### Страница отдельного проекта — в будущем

Может содержать:

- Название и дату.
- Описание проекта.
- Изображения или скриншоты.
- Технические подробности.
- Ссылки на GitHub и демо.

**Не планируем в первой версии:** About, Blog, Services, Skills и другие дополнительные разделы.

## 4. Header

- Слева: `PORTFOLIO`.
- Справа: `Home`, `Projects`, `GitHub`.
- Активный пункт меню выделяется акцентным цветом.
- Компактная высота.
- Без массивной панели и лишнего декора.

## 5. Hero

Компактный блок, не занимающий всю высоту экрана.

Содержимое:

- Крупный заголовок `PORTFOLIO`.
- Подзаголовок `Projects • Experiments • Ideas`.
- Внешняя ссылка на GitHub.
- Кнопка `Explore projects`.

Ссылка на GitHub расположена между описанием и кнопкой.

### Кнопка Explore projects

- Прозрачный фон.
- Тонкая фиолетовая обводка.
- Светлый текст.
- Небольшое скругление.
- При наведении — лёгкая фиолетовая заливка.
- Без яркого неонового свечения.

На главной кнопка ведёт к секции проектов.

## 6. Лента проектов

Проекты располагаются **вертикально, как публикации**, а не сеткой карточек.

Каждая публикация в будущем может содержать:

- Название.
- Дату.
- Короткое описание.
- Изображение при необходимости.
- Ссылку на отдельную страницу проекта.

### Пустое состояние

Пока проектов нет, отображается простой текст:

> Здесь появятся первые проекты.

Без вымышленных работ, заглушек с фальшивым содержимым и лишних карточек.

## 7. Footer

Минимальный:

`© 2026 PORTFOLIO`

Без дополнительных колонок и повторения навигации.

## 8. Адаптивность

- Удобное отображение на телефонах и компьютерах.
- Единая максимальная ширина контента.
- Читаемые размеры текста.
- Достаточные отступы.
- Простая адаптация навигации.

## 9. Чего избегаем

- Ретро-терминального интерфейса.
- Звёзд, частиц и анимированных фонов.
- Ретросолнца, гор и неоновых сеток.
- Сильного свечения.
- Сложных анимаций.
- Перегруженных карточек.
- Лишних разделов.
- Декора без практического назначения.

**Synthwave выражается прежде всего в палитре, а не в декоративных иллюстрациях.**

## 10. Технологии

Первая версия:

- HTML.
- CSS.
- Git.
- GitHub.

Без React, Astro и сложной системы сборки.

Дополнительные технологии подключаются только при реальной необходимости.

## 11. Возможности развития

В будущем, по мере появления контента:

- Добавлять проекты в ленту.
- Создавать подробные страницы проектов.
- Добавлять скриншоты и демо.
- Улучшать навигацию при необходимости.

Не реализовывать эти возможности заранее без потребности.

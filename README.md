# Portfolio

Личный сайт для проектов, экспериментов и идей в стиле Minimal Synthwave.
Первая версия использует HTML и CSS без зависимостей и сборки.

## Структура

- `index.html` — главная страница.
- `projects/index.html` — полный список проектов.
- `styles/main.css` — общие стили и адаптивная компоновка.
- `DESIGN.md` — концепция сайта.
- `CHANGELOG.md` — история заметных изменений сайта.

## Локальный просмотр

Откройте `index.html` в браузере. Установка дополнительных инструментов не нужна.
Относительные ссылки работают при просмотре файлов и размещении сайта в подпапке.

При размещении на статическом хостинге страница проектов доступна по `/projects/`
(для GitHub Pages проекта — по `/portfolio/projects/`).
